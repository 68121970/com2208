1. เทคโนโลยี (Technology) ความหมาย เทคโนโลยี คือ การนำความรู้ เครื่องมือ วิธีการและทักษะทางวิทยาศาสตร์มาประยุกต์ใช้เพื่อแก้ปัญหาหรือเพิ่มประสิทธิภาพในการดำเนินชีวิตและการทำงาน
ตัวอย่างที่ 1 : สมาร์ตโฟน
ในอดีตการติดต่อสื่อสารต้องใช้โทรศัพท์บ้านหรือส่งจดหมาย แต่ปัจจุบันสามารถใช้สมาร์ตโฟนโทร ส่งข้อความ ประชุมออนไลน์ หรือเรียนออนไลน์ได้
ปัญหาเดิม: ติดต่อสื่อสารได้ยาก
เทคโนโลยีที่ใช้: สมาร์ตโฟนและอินเทอร์เน็ต
ผลลัพธ์: สื่อสารได้สะดวกและรวดเร็ว
ตัวอย่างที่ 2 : หุ่นยนต์ในโรงงาน
โรงงานใช้หุ่นยนต์ช่วยประกอบชิ้นส่วนสินค้าแทนแรงงานคน
ลดความผิดพลาด
เพิ่มความรวดเร็วในการผลิต
ลดต้นทุนระยะยาว



2. นวัตกรรม (Innovation) ความหมาย นวัตกรรม คือ การนำความคิดสร้างสรรค์ ความรู้ หรือเทคโนโลยีมาพัฒนาเป็นสิ่งใหม่หรือปรับปรุงสิ่งเดิมให้ดีขึ้นจนเกิดคุณค่าและสามารถใช้งานได้จริง 
ตัวอย่างที่ 1 : แอปพลิเคชันสั่งอาหาร
เมื่อก่อนต้องโทรสั่งอาหารกับร้านโดยตรง
ปัจจุบันมีแอป เช่น GrabFood หรือ Foodpanda
ลูกค้าสั่งอาหารผ่านมือถือ
ติดตามสถานะการส่งได้
ชำระเงินออนไลน์ได้
นี่คือนวัตกรรม เพราะเป็นการนำเทคโนโลยีมาสร้างบริการที่ตอบสนองความต้องการของผู้ใช้ได้ดีกว่าเดิม
ตัวอย่างที่ 2 : E-Learning
จากการเรียนในห้องเรียนเพียงอย่างเดียว พัฒนามาเป็นการเรียนออนไลน์
เรียนได้ทุกที่
เรียนย้อนหลังได้
ประหยัดเวลาและค่าเดินทาง

 Innovation Framework ความหมาย Innovation Framework คือ กรอบแนวทางในการสร้างนวัตกรรมอย่างเป็นระบบ ตั้งแต่การค้นหาปัญหา การคิดไอเดีย การพัฒนา จนถึงการนำไปใช้งานจริง 
ตัวอย่าง
กรณีปัญหาในมหาวิทยาลัยนักศึกษามาสายเพราะหาห้องเรียนไม่เจอ
ขั้นตอน
1. ค้นหาปัญหา สอบถามนักศึกษาพบว่าป้ายอาคารไม่ชัดเจน
2. คิดแนวทางแก้ไข ทำแผนที่ดิจิทัลพัฒนาแอปนำทางในมหาวิทยาลัย
3. สร้างต้นแบบ ออกแบบหน้าจอแอป
4. ทดลองใช้ ให้นักศึกษาทดลองใช้
5. นำไปใช้งานจริงเปิดใช้งานทั้งมหาวิทยาลัยนี่คือตัวอย่างการใช้ Innovation Framework เพื่อแก้ปัญหาอย่างเป็นขั้นตอน

3. Design Thinking ความหมาย Design Thinking คือ กระบวนการคิดเชิงออกแบบที่เน้นการเข้าใจผู้ใช้เป็นศูนย์กลาง เพื่อหาแนวทางแก้ไขปัญหาที่ตรงกับความต้องการของผู้ใช้มากที่สุด 
ตัวอย่าง
ปัญหา นักศึกษาลืมส่งงานบ่อย
ขั้นตอน Design Thinking
1. Empathize (เข้าใจผู้ใช้) สัมภาษณ์นักศึกษา พบว่า งานเยอะ,ลืมกำหนดส่ง,มีหลายวิชา
2. Define (กำหนดปัญหา) ปัญหาหลักคือ"นักศึกษาต้องการระบบแจ้งเตือนที่ช่วยไม่ให้ลืมส่งงาน"
3. Ideate (สร้างแนวคิด) ระดมไอเดีย แอปแจ้งเตือน,ปฏิทินออนไลน์,ระบบแจ้งเตือนผ่าน Line
4. Prototype (สร้างต้นแบบ) สร้างหน้าจอจำลองของแอปแจ้งเตือนงาน
5. Test (ทดสอบ)ให้นักศึกษาทดลองใช้หากพบข้อบกพร่องก็ปรับปรุงต่อไป
